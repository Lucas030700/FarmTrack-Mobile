# FarmTrack Mobile

Phone-first installable Progressive Web App demo for managing farm lots, activities, inventory, and schedules.

## Publish
Enable GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root). Open the HTTPS Pages URL on your phone.

## Install on phone
- Android Chrome: browser menu → Install app / Add to Home screen.
- iPhone Safari: Share → Add to Home Screen.

## Demo features
- Dashboard and land overview
- Add land and view per-land details
- Production activities and completion tracking
- Inventory stock-in and stock-out demo
- Farm calendar and task schedule
- Local browser persistence and offline app-shell cache

## Limitations
This is a front-end demonstration. Data is stored only in the current browser/device. There is no sign-in, cloud database, cross-device sync, push notification, or live weather. Sample farm names, amounts, quantities, and dates are fictional. Validate crop calendars and input rates against actual field conditions and local agricultural guidance.
